# PanLite 发布验收记录模板

此文件是待填写的记录模板，不代表任何版本已经通过。每次发布复制一份到独立记录位置，并填写版本、提交、执行人、日期、环境及证据链接或路径。不要提交真实凭据或用户数据。

## 发布候选信息

| 字段 | 填写内容 |
| --- | --- |
| 版本 / Git 提交 | 待填写 |
| 构建机器与 Node/npm 版本 | 待填写 |
| Windows 隔离环境版本与架构 | 待填写 |
| 安装包文件名与 SHA-256 | 待填写 |
| 签名证书发布者、有效期、时间戳 | 待填写 |
| 执行人、日期、证据位置 | 待填写 |

## 自动门禁

每一项记录命令输出、退出码和报告路径。某项未执行时填写“未执行”，不要留作默认通过。

| 检查 | 结果与证据 |
| --- | --- |
| `npm ci` | 待填写 |
| `npm run check` | 待填写 |
| `npm run test:task-coverage` | 待填写 |
| `npm run security:audit` | 待填写 |
| Windows CI 构建与打包任务 | 待填写 |
| `npm run pack` 或签名发布构建 | 待填写 |
| `npm run checksums` 与 SHA-256 复核 | 待填写 |
| `npm run release:verify`（正式签名包） | 待填写 |
| 包内原生 SQLite 加载、启动和主界面检查 | 待填写 |

## 隔离环境安装与升级

`npm run test:install` 只验证干净环境中的静默安装、隔离用户目录启动和卸载；它不覆盖交互安装、旧版用户数据升级或回滚。以下场景须在一次性 Windows VM 或专用测试机上记录。

| 场景 | 结果与证据 |
| --- | --- |
| 干净环境交互安装、桌面快捷方式、启动、关闭、卸载 | 待填写 |
| 旧版安装及测试账号数据准备；升级前备份用户数据目录 | 待填写 |
| 安装候选版后账号、设置、任务、AI 数据与本地附件检查 | 待填写 |
| 使用代表性真实测试账号执行读写、分享和跨网盘迁移 | 待填写 |
| 运行中任务与应用内更新提示、下载、重启后状态（仅签名更新版） | 待填写 |
| 故障回滚：关闭应用、恢复升级前用户数据及旧版程序、核对数据 | 待填写 |
| 卸载后用户数据保留或删除行为与预期一致 | 待填写 |
