# PanLite 发布验收记录模板

此文件是待填写的记录模板，不代表任何版本已经通过。每次发布复制一份到独立记录位置，并填写版本、提交、执行人、日期、环境及证据链接或路径。不要提交真实凭据或用户数据。

## 发布候选信息

| 字段 | 填写内容 |
| --- | --- |
| 版本 / Git 提交 | 待填写 |
| 构建机器与 Node/npm 版本 | 待填写 |
| Windows 隔离环境版本与架构 | 待填写 |
| 安装包文件名与 SHA-256 | 待填写 |
| 发行渠道及签名状态 | 默认未签名 Windows 安装包；若选签名渠道，填写发布者、有效期与时间戳 |
| 执行人、日期、证据位置 | 待填写 |

## 自动门禁

每一项记录命令输出、退出码和报告路径。某项未执行时填写“未执行”，不要留作默认通过。

| 检查 | 结果与证据 |
| --- | --- |
| `npm ci` | 待填写 |
| `npm run check` | 待填写 |
| `npm run test:task-coverage` | 待填写 |
| `npm run security:audit` | 待填写 |
| Windows CI 构建与打包任务 | 待填写 |
| `npm run pack`（默认未签名发行） | 待填写 |
| `npm run checksums` 与 SHA-256 复核 | 待填写 |
| `npm run release:verify`（仅签名渠道） | 未签名发行填写“不适用”；选签名渠道时须有通过证据 |
| 包内原生 SQLite 加载、启动和主界面检查 | 待填写 |
| `build-provenance.json` 的提交、锁文件、源码哈希及构建后 `--verify` | 待填写；含未提交改动只能记为本地候选 |

## 隔离环境安装与升级

`npm run test:install` 默认验证干净环境中的静默安装、隔离用户目录启动和卸载；加 `-BaselineInstaller`、`-BaselineSha256`、`-BaselineVersion` 后，验证由旧版初始化的隔离数据库内合成账号、设置、暂停任务、AI 文档与附件的升级保留和离线备份回滚。无基线时 `releaseUpgradeGatePassed=false`。Windows CI 默认使用固定哈希的 `v0.2.2` 旧包执行完整自动演练。脚本不验证凭据解密、真实登录、交互安装或日常用户目录；以下项目仍须分别记录。

| 场景 | 结果与证据 |
| --- | --- |
| 自动静默安装及旧版合成数据升级/离线回滚；`install-smoke.json` 的 upgrade、rollback 和 `releaseUpgradeGatePassed` | 待填写；合成结果不能代替下方真实账号验收 |
| 干净环境交互安装、桌面快捷方式、启动、关闭、卸载 | 待填写 |
| 同次候选 `install-wizard` 控件流程、快捷方式目标、注册项删除及默认 APPDATA 合成标记保留 | 待填写 `wizard-report.json`；不代替模式选择、视觉审查或真实用户库 |
| 旧版安装及测试账号数据准备；升级前备份用户数据目录 | 待填写 |
| 安装候选版后账号、设置、任务、AI 数据与本地附件检查 | 待填写 |
| 使用代表性真实测试账号执行读写、分享和跨网盘迁移 | 待填写 |
| 运行中任务与应用内更新提示、下载、重启后状态（仅签名更新版） | 待填写 |
| 故障回滚：关闭应用、恢复升级前用户数据及旧版程序、核对数据 | 待填写 |
| 卸载后用户数据保留或删除行为与预期一致 | 待填写 |

性能另存同机原始样本、运行时、显示配置、采样顺序和复核结论。`release-startup-comparison` 的发布载荷比较不能伪装为相同 Electron/显示配置的源码对照；任何 review-regression 仍需解释或明确保留。
