## 下一轮验收方法

1. 在独立用户数据目录和专用测试账号中运行，不读取系统浏览器资料；记录应用版本、平台、日期、账号类型、操作与结果。报告只保存匿名账号代号，不保存 Cookie、Token、二维码、文件正文或临时下载链接。
2. 先验登录与只读操作：首次扫码、过期二维码、切换账号、已有会话、断网恢复、目录分页、精确搜索、下载字节校验、图片/PDF/Office/压缩包预览，以及视频 200/206/416、跳转、取消和重新打开。
3. 对云端写入另行限定范围，仅在明确授权的测试目录中执行新建、上传、重命名、分享、转存、迁移和清理；每项验证最终状态与重复执行结果。
4. 每个平台记录“通过、失败、未测、平台不支持”之一，并附脱敏请求状态、错误类别和可复现步骤。接口失败不可自动改写为“功能可用”。

发布门禁：扫码登录至少完成三个平台各一次真实登录及切换账号验证；未验收的平台在公开说明中保留“待验收”标记。若无法取得测试账号，发布说明应明确该限制。
