# 功能与真实账号验收清单

更新时间：2026-10-11

## 如何阅读

下表依据 `src/shared/capabilities.ts`、`src/adapters/registry.ts` 和账号添加界面整理，表示当前代码声明并接入的能力。✅ 不代表第三方接口已在真实账号上通过端到端验收；平台接口、账号权限与套餐限制还需要分别验证。

| 平台 | 浏览/搜索/基本文件操作 | 文件上传/下载 | 创建分享/链接转存 | 关键限制 |
| --- | :---: | :---: | :---: | --- |
| 百度网盘 | ✅ | ✅/✅ | ✅ | 网页会话、OAuth 和 Cookie 路径应分别验收 |
| 夸克网盘 | ✅ | ✅/✅ | ✅ | 网页会话和 Cookie 路径应分别验收 |
| UC 网盘 | ✅ | ✅/✅ | ✅ | 网页会话和 Cookie 路径应分别验收 |
| 迅雷网盘 | ✅ | ✅/✅ | ✅ | 网页授权与 Refresh Token 路径应分别验收 |
| WebDAV | ✅ | ✅/✅ | — | WebDAV 协议没有分享链接/转存能力 |
| 阿里云盘开放平台 | ✅ | ✅/✅ | — | 开放平台接口没有此处所需的分享能力 |
| 123 云盘开放平台 | ✅ | ✅/✅ | — | 开放平台接口没有此处所需的分享能力 |

跨网盘文件迁移需来源支持下载、目标支持上传。压缩包创建由客户端下载、压缩再上传完成，也受目标上传能力约束。自动化、批量任务和 AI 工作台应在基本文件操作稳定后另行验收。

## 每个平台的最小验收

在隔离测试账号和可清理的测试目录中记录以下操作。遇到套餐、配额、验证码或频率限制，应记录实际限制与响应，不将跳过算作通过。

| 场景 | 证据 |
| --- | --- |
| 登录、刷新凭据、退出和重新登录 | 平台、接入方式、时间、脱敏错误码 |
| 根目录与多页子目录浏览、搜索、空目录 | 文件数量、分页边界、路径一致性 |
| 小文件与大文件上传/下载、取消、重试、校验 | 源与目标 SHA-256、任务日志 |
| 重命名、移动、复制（平台支持时）、删除 | 远端最终状态与本地列表刷新 |
| 分享创建、提取码、过期、取消、链接转存（平台支持时） | 分享状态与目标目录结果，敏感链接脱敏 |
| 跨账号及跨平台迁移 | 来源/目标组合、文件与目录结构、冲突策略、SHA-256 |

## 其他待验收范围

- **安装与升级**：干净 Windows 环境中的安装、已安装应用启动、卸载、旧版资料升级及完整回滚，见 [发布验收表](RELEASE_ACCEPTANCE.md)。
- **后台任务**：应用退出与重启后的任务恢复、暂停、重试、取消，以及结果不明的远端操作处理。单个任务内的操作键不能保证第三方平台的远端 exactly-once。
- **文件与自动化**：文件备份的版本、恢复预览和保留策略；目录索引的重建与离线行为；自动化规则的触发、停用和重复执行。
- **AI 工作台**：本地文件和用户主动选择的网盘文件导入，PDF/OCR、Office、压缩包、音视频及引用定位；分别记录本地工具和云端 Provider 的配置、输出与数据流向。
- **平台实时兼容性**：每次正式发布前抽查全部接入平台。模拟测试和历史只读账号测试不能替代上述写入、删除、分享与迁移验收。

验收记录应写明软件版本、提交、环境、测试账号类型、执行人、时间、结果及证据位置；不要在仓库中保存 Cookie、Token、密码或原始分享链接。
