# PanLite 界面升级规范

PanLite 的界面定位是清晰、可靠的桌面网盘工作台。文件与任务内容优先，颜色用于指出当前操作与状态；装饰不能抢占阅读空间。浅色工作区采用中性浅灰背景和白色内容面，深蓝侧栏提供稳定的导航锚点；深色模式沿用相同的层级和语义。

## 页面骨架

每个页面依次提供标题区、主要操作、内容区以及必要的反馈。标题区包含一个简短分类标签、唯一的页面标题和一句说明；右侧只放当前页面最重要的操作。文件管理的账号切换与搜索放在顶部工具栏，目录操作放在路径栏；账号管理与 AI 工作台使用自己的页面操作区。

标题使用 `pl-page-heading` 和 `pl-eyebrow`，内容容器使用 `pl-surface`，分区标题使用 `pl-section-heading`。这些类只负责通用视觉结构，页面组件继续负责自身布局与行为。样式变量集中在 `src/renderer/styles/tokens.css`；新页面优先使用语义变量，不再新增只适用于浅色主题的固定色值。

## 视觉规则

| 元素 | 规则 |
| --- | --- |
| 字体层级 | 页面标题 24px，分区标题 19px，正文 13–14px，辅助说明至少 12px。标题通过字重和间距建立层级。 |
| 间距 | 以 4px 为基础；控件内部通常 8–12px，卡片内部 16–24px，页面区块之间 14–20px。 |
| 颜色 | 主蓝用于当前导航、主要按钮及可操作链接；绿色、橙色、红色只表示成功、提醒、危险。 |
| 容器 | 使用 `--pl-surface`、`--pl-border`、`--pl-radius-card` 和 `--pl-shadow-card`；悬浮反馈仅在可交互容器上使用。 |
| 图标 | 同一操作使用同一图标；图标按钮必须有可见焦点和可读名称。 |
| 表格 | 表头、行、悬浮、选中与加载遮罩均使用主题变量；触屏设备上的行操作始终可见。 |
| 动效 | 只表达状态切换与轻微反馈；遵守 `prefers-reduced-motion`。 |

## 状态与操作

所有高频页面应覆盖：首次使用、加载中、空结果、失败、离线缓存、部分能力不可用和成功反馈。空状态解释下一步，错误状态说明可恢复操作。危险操作保留确认步骤；禁用按钮提供原因。批量操作在选中后出现，并始终显示选中数量。

键盘用户应能到达导航、工具栏、表格操作、弹窗和搜索结果；焦点样式在浅色、深色侧栏和内容区都必须清楚。窄窗口先压缩次要信息，再允许局部横向滚动，不隐藏关键操作。全局只保留一个主要垂直滚动容器，聊天等专用工作区例外。

## 改造顺序与验收

1. 全局侧栏、顶部工具栏、主题令牌和页面骨架。
2. 文件管理、在线预览、上传下载、账号管理与登录。
3. 搜索、转存、迁移、任务与分享。
4. AI 工作台、备份、空间分析、安全和设置。

每批改造都要在浅色和深色下检查主要页面，覆盖 1280×800 与 1600×900 等桌面窗口；检查长文件名、无账号、空目录、加载、禁用操作、键盘焦点和弹窗。运行 lint、类型检查、渲染构建及涉及页面的测试。截图只通过离屏测试生成，不启动可见窗口或操控用户桌面。
